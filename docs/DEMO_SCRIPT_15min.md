# 15분 시연 스크립트 — 구매 요청서 누락 확인 (M03 공통 시연)

- 위치: M03 PoC 설계, 전체 교육 약 2시간 30분 경과 시점
- 제목: 문서에서 뽑고, 빈칸을 표시하고, 사람이 확정한다
- 판단 기준: "문서 생성 성공"이 아니라 "추가 문의 항목을 찾았는가"
- 화면 준비: ① ChatGPT 새 대화(시스템 규칙 붙여 둠) ② `out/D04_누락표시표_활동지.xlsx` '누락표시표' 시트 ③ `examples/D04_잘못된초안_예시.md` ④ 오프라인 폴더 `examples/D04_오프라인_추출결과/`
- 손 자료: 필수 항목표·용어 사전 1장(활동지 시트 인쇄), 조별 표본 배정표(README 표)

## 0–2분 · 도입

**강사 발화**
> 「현업에서 가장 체감하는 거는 지루한 반복작업을 지워주는 일」— 오늘 오전에 여러분이 흐름도에 표시한 그 반복이, 현장지원팀에서는 "불완전한 요청 → 다시 물어보기"였습니다. 이제 그 한 단계만 놓고 작은 실험을 합니다.

> 결과물은 이 표 하나입니다. (활동지 '누락표시표' 띄움) 열이 세 종류로 나뉩니다. **원문 값**, **AI 제안**, **사람 확정**. 성공 기준은 "예쁜 문서가 나왔나"가 아니라 "**추가로 물어봐야 할 항목을 찾았나**"입니다.

**확인**: 학습자가 활동지 열 구분(원문/후보/확인 필요/사람 확정)을 눈으로 확인했는가.

## 2–6분 · 시연 (D04-13)

원문: `A현장, 품목 P-01 20개, 다음 주 필요.`

1. ChatGPT에 `prompts/01_추출.md` 붙이고 원문 입력 → JSON 수신. (접속 불가 시 `시연_D04-13.json` 열기)
2. JSON을 읽으며 강조:
   - 품목 ID `P-01`, 수량 `20`, 단위 `개` → 원문 값 그대로. 표준명 후보 "볼밸브 50A"는 **사전에서 온 제안**.
   - 희망일 `다음 주` → 메모 "날짜로 변환하지 않음". **여기서 멈추는 것이 규칙**.
   - 배송 위치 `A현장` → 세부 위치 없음.
   - 규격 → null. 원문에 없다.
3. `prompts/02_규칙검사보조.md` 실행 또는 활동지 상태 열 직접 채우기:
   - 희망일 **모호**, 배송 위치 **모호** → "확인 필요" 2건. 규격은 품목 ID가 확정됐으니 규칙으로 "사전 규격 50A 적용" — 이건 규칙 열에 근거를 남긴다.
4. `prompts/03_보완질문.md` → 질문 2개. 사람 확정 칸은 비어 있음을 보여 준다.

**강사 발화(핵심)**
> AI가 잘한 일은 셋입니다. 읽었다, 나눴다, 물어볼 문장을 썼다. AI가 하지 않은 일도 셋입니다. 날짜를 정하지 않았다, 창고를 정하지 않았다, 발주 가능이라고 말하지 않았다.

**확인**: 체크리스트에 원문/후보/확인필요 열이 구분되어 표시됐는가.

## 6–8분 · 실패 장면

`examples/D04_잘못된초안_예시.md` 띄움. 같은 원문에서 "친절한" AI가 낸 초안:
- 희망일 `2026-09-24` ("다음 주 → 수요일 기준으로 정리")
- 배송 위치 `A현장 3동 자재창고` ("통상 자재창고")
- 규격 `50A` (원문에 없음)
- 사람 확정 `이상 없음, 발주 진행 가능`

게이트 검사 결과 표를 보여 준다: **G2 · G1 · G4 · G5** 네 건.

**강사 발화**
> 이 초안이 더 완성돼 보입니다. 그래서 더 위험합니다. 9/24에 현장이 자재를 기다리는데 요청자는 9/28을 생각했다면, 추가 문의가 아니라 오배송입니다. 원문에 없는 값은 빈칸으로 두는 것이 이 PoC의 첫 번째 규칙입니다.

**학습자 활동**: 활동지 비고 칸에 "위험 한 줄" 작성. (예: "그럴듯한 값이 원문 근거 없는 값이다")

## 8–13분 · 조별 실습

배정(`examples/D04_오프라인_추출결과/README.md`):

| 조 | 문서 | 왜 이 표본인가 |
|---|---|---|
| 1조 | D04-08 | 별칭 '볼밸브'만 → P-01/P-02 후보, 규격 누락. **병합 금지** 확인 |
| 2조 | D04-15 | '엘보' 후보 2개(90도/45도) + '이번 달 안' |
| 3조 | D04-19 | 단위 불일치(본 ↔ m). 규칙 열의 힘 |
| 4조 | D04-26 | 배송 위치 자체가 없음 → 누락 vs 모호 구분 |
| 5조 | D04-03S | 저품질 스캔 `5OA` → 판독 불가는 사람 판단 |
| 6조 | D04-12 | 복합 결함 4건. 질문 우선순위 |

**안내**
> 자기 조 표본 1건으로 활동지에 (1) 원문 값 (2) 확인 필요 항목 (3) 사람 확정 칸 담당자만 채우세요. 5분입니다. 값이 없으면 비웁니다. 후보 B·C 조도 같은 뼈대입니다 — 입력 1건, 필수 항목, 사람이 확정하는 칸.

**강사 순회 확인 질문**
- "이 값은 원문 어디에 있나요?" (추적)
- "이 후보를 한 품목으로 확정한 근거가 규격인가요, 이름인가요?" (G3)
- "사람 확정 칸에 왜 이미 값이 있나요?" (G5)

**시간 초과 시**: 사람 확정 칸만 채우게 하고, 보완 질문은 M03 기획안 작성 35분으로 넘긴다.

## 13–15분 · 성공 기준 미리보기·연결

활동지 '검증지표표' 시트 띄움.

> 이 PoC가 성공했는지 어떻게 알까요? 네 가지 숫자입니다. **누락 탐지율 95%**, **잘못된 경고 10% 이하**, **중요 오류 0건**, **원문 추적 100%**. 그리고 시간은 **사람의 검토 시간을 포함해서** 잽니다. 소표본 0건은 운영 무오류가 아니라는 말도 기획안에 적습니다.

> 다음 20분은 여러분 조의 '필수 항목표'와 '정답 기준'을 만드는 시간입니다. 오늘 시연에서 쓴 6개 항목은 배관 자재군 예시일 뿐입니다.

**질문 1개 받기.** 예상 질문과 답:
- "규격을 사전에서 채운 건 원문 없는 값 아닌가?" → 규칙 열에서 근거를 남기고 적용한 것과, AI가 원문값 칸에 채운 것은 다르다. 표에서 열이 다르다.
- "ChatGPT가 매번 다르게 답하면?" → 그래서 게이트 검사와 정답표가 있다. 출력이 아니라 규칙을 믿는다.
