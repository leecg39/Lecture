## 2. 학습자 경로 재현에서 발견한 것

| # | 발견 | 조치 |
|---|---|---|
| M | ChatGPT는 JSON을 ```` ```json ```` 코드블록과 설명 문장으로 감싸 준다. 파일 저장 후 `check-paste`가 즉시 실패 | `strip_code_fence`: 코드블록 본문 또는 첫 `{`~마지막 `}` 추출. CLI는 문자열을 로더에 넘김. 회귀 테스트 `test_M_code_fence_and_prose_are_stripped` |
| N | 잘못된 초안은 **규칙 검사만으로는 확인 필요 0건**으로 통과한다 | 이것이 실패 장면의 핵심 교훈이므로 예시 문서 "왜 위험한가" 첫 줄에 명시. 게이트 없는 규칙은 지어낸 값을 못 잡는다 |
| O | 게이트 위반 문서 수준 항목이 `None`으로 표시 | `(문서)`로 표기 |
| P | 후보 B·C 조는 공통 시연 뼈대는 있지만 자기 조 자료가 없어 8–13분 실습이 공회전할 위험 | 후보 B 견적 6행(단위 m↔본, 배송비 미기재, 규격 미기재 함정), 후보 C 발주 5건(잔량·미갱신·갱신자 공란) + 전용 시트. 로직은 넣지 않음(PRD 비목표 유지) |
