아래 구매 요청서 원문에서 필수 항목 6개를 추출해 JSON으로만 답하세요. 설명 문장은 쓰지 않습니다.

출력 형식(항목 6개를 모두 포함, 없는 값은 null):
{
  "항목": [
    {"항목ID": "품목 ID", "원문값": "...", "원문발췌": "...", "표준명후보": "...", "메모": null},
    {"항목ID": "수량", "원문값": "...", "원문발췌": "...", "표준명후보": null, "메모": null},
    {"항목ID": "단위", "원문값": "...", "원문발췌": "...", "표준명후보": "표준 단위", "메모": null},
    {"항목ID": "희망일", "원문값": "...", "원문발췌": "...", "표준명후보": null, "메모": null},
    {"항목ID": "배송 위치", "원문값": "...", "원문발췌": "...", "표준명후보": null, "메모": null},
    {"항목ID": "규격", "원문값": "...", "원문발췌": "...", "표준명후보": null, "메모": null}
  ]
}

작성 규칙:
- 원문값과 원문발췌는 원문에서 그대로 복사합니다. 고치거나 정규화하지 않습니다.
- 품목 ID가 없고 별칭만 있으면 원문값에 별칭을 적고, 표준명후보에 가능한 품목을 모두 적습니다. 예: "P-01 볼밸브 50A / P-02 볼밸브 100A (규격 확인)".
- 희망일이 "다음 주"처럼 모호하면 원문값에 그 표현을 그대로 적고 메모에 "모호 표현, 날짜로 변환하지 않음"이라고 적습니다.
- 배송 위치는 현장명과 세부 위치를 함께 적습니다. 현장명만 있으면 현장명만 적고 메모에 "세부 위치 없음"이라고 적습니다.
- 규격이 원문에 없으면 원문값 null. 품목 ID가 있어도 규격 칸에 사전 값을 채우지 않습니다(그건 규칙 검사 단계에서 합니다).
- 읽기 어려운 글자는 보이는 대로 적고 메모에 "판독 불가"라고 적습니다.
