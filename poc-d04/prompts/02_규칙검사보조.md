앞서 추출한 JSON을 필수 항목표에 대조해 항목마다 상태를 붙이세요. 상태는 네 가지 중 하나입니다: 충족 / 누락 / 모호 / 불일치.
이 단계는 "규칙"입니다. 새로운 값을 추측하지 말고 아래 표만 적용하세요.

| 항목 | 충족 | 모호 | 불일치 | 누락 |
|---|---|---|---|---|
| 품목 ID | P-NN이 원문에 있고 사전에 존재 | 별칭만 있음 / 후보 2개 이상 / 판독 불가 | P-NN이 사전에 없음 | 값 없음 |
| 수량 | 양의 정수 | 판독 불가 | 0 이하 | 값 없음 |
| 단위 | 사전 표준 단위와 같음(EA=개, M=m) | 품목 미확정으로 비교 불가 / 판독 불가 | 표준 단위와 다름 | 값 없음 |
| 희망일 | 특정 날짜 | 모호 표현 / 판독 불가 | 요청일(2026-09-17) 이전 | 값 없음 |
| 배송 위치 | 현장명 + 세부 위치 | 현장명만 | — | 값 없음 |
| 규격 | 규격 토큰이 있음, 또는 품목 ID 확정으로 사전 규격 적용 가능 | 판독 불가 | 품목 ID의 사전 규격과 다름 | 품목 ID 없고 규격도 없음 |

출력 형식(JSON만):
{
  "항목": [
    {"항목ID": "품목 ID", "원문값": "...", "상태": "충족|누락|모호|불일치", "근거": "적용한 규칙 한 줄", "확인필요": true|false}
  ],
  "확인필요항목": ["희망일", "배송 위치"]
}

주의:
- "확인필요"는 상태가 충족이 아닐 때 true입니다.
- 근거에는 원문 표현과 적용한 규칙만 씁니다. "아마", "보통", "~일 것" 같은 추정 표현을 쓰지 않습니다.
- 사람 확정 칸은 만들지 않습니다. 확정은 사람이 스프레드시트에서 합니다.
